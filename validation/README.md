# Manuscript validation package

This directory contains the data and archived outputs used to support the illustrative validation reported in the SoftwareX manuscript.

## Contents

- `input/thermal_validation.png`: thermal capture `capture_20260529_125321` used in the manuscript example.
- `results/<ALGORITHM>/Batch_<ALGORITHM>_Mth.xlsx`: archived numerical output for DE, DESSA, SDE, GWO, PSO, CSA, and FA at 2, 3, 4, and 5 thresholds.
- `results/<ALGORITHM>/*_thr5_*.png`: representative five-threshold segmented image, histogram, and convergence plot from the archived experiment.
- `summary/numerical_results.csv`: machine-readable transcription of the seven archived workbooks for all four threshold levels.
- `summary/optimizer_summary.csv`: manuscript-level ranking summary. Ties use competition/minimum ranking (equal best values receive rank 1), matching the method used in the article.
- `convergence/`: location for per-run numerical convergence traces generated by the current release.

## Convergence-data note

The archived validation run predates the per-run CSV convergence export added to the current software release. Its original convergence outputs are preserved as PNG plots under `results/<ALGORITHM>/`. The current release writes one CSV trace and one PNG plot for every stochastic run. To regenerate numerical convergence traces with the current release, build `segm` and execute the command documented in `regenerate_validation.sh`.

Because the optimizers are stochastic, a regenerated run is expected to be statistically comparable but is not expected to reproduce an identical convergence trajectory unless an algorithm-specific deterministic seed is explicitly supported and selected.

## Relationship to the manuscript

The detailed DE values in the manuscript are taken from `results/DE/Batch_DE_Mth.xlsx`. The seven-optimizer summary is derived from all seven workbooks and is provided in `summary/optimizer_summary.csv`. The original input and representative five-threshold outputs are included so that reviewers can trace the reported example to the archived artifacts.
